📋 Download Template

Secondary button with download icon for easy template access.

📅 Date Selection

Configurable date modes (Excel Date, Selected Date, custom).

Consistent with app design system. Dark mode included.

Works perfectly on mobile, tablet, and desktop screens.

Custom children prop for module-specific results display.

🚀 Quick Start

To use the ImportDialog component in any module:

import ImportDialog from '../../components/common/ImportDialog'; <ImportDialog isOpen={showImportModal} onClose={() => setShowImportModal(false)} title="Import Data" description="Upload your Excel file" onImport={handleImport} onFileChange={handleFileChange} onDownloadTemplate={handleDownloadTemplate} importing={importing} downloading={downloading} importForm={formState} dateConfig={dateConfig} > {/* Custom results display */} </ImportDialog>
